# Arithmetic Helpers

Four single-page tools that work through an arithmetic problem step by step, the way it's done on paper.

| Page | What it does |
| --- | --- |
| [The Carry Column](addition.html) | Addition of whole numbers, decimals (2–4 numbers) and fractions, with every carry shown |
| [The Borrow Bank](subtraction.html) | Subtraction with every borrow crossed out and written above |
| [The Product Ladder](multiplication.html) | Multiplication with partial products, then placing the decimal point |
| [The Division House](division.html) | Long division with remainders, decimals (including repeating) or fractions |

Every page also has:

- a plain-English explanation of each step
- a **One step at a time** mode for practice
- a **tape diagram** and an **area model** for both decimals and fractions
- light and dark themes, and a print layout

Each page is one self-contained HTML file with no build step. Open it in a browser, or use the live site:
<https://chrisdfennell.github.io/arithmetic-helpers/>
