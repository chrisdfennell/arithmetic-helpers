# Arithmetic Helpers

Seven single-page tools that work through a math problem step by step, the way it's done on paper.

| Page | What it does |
| --- | --- |
| [The Carry Column](addition.html) | Addition of whole numbers, decimals (2–4 numbers) and fractions, with every carry shown |
| [The Borrow Bank](subtraction.html) | Subtraction with every borrow crossed out and written above |
| [The Product Ladder](multiplication.html) | Multiplication with partial products, then placing the decimal point |
| [The Division House](division.html) | Long division with remainders, decimals (including repeating) or fractions |
| [The Order Stack](pemdas.html) | Order of operations (PEMDAS) for long problems with + − × ÷, parentheses and exponents, plus a problem maker |
| [The Balance Scale](algebra.html) | Algebra: simplifying expressions, solving equations and inequalities, and systems of two equations |
| [The Shape Shop](geometry.html) | Geometry: area and perimeter, volume and surface area, the Pythagorean theorem, and angles |

Every page also has:

- a plain-English explanation of each step
- a **One step at a time** mode for practice
- a picture of the problem: **tape diagrams** and **area models** on the arithmetic pages, an **expression tree** for the order of operations, balance scales, number lines and graphs for algebra, and shapes drawn to scale for geometry
- light and dark themes, and a print layout

Each page is one self-contained HTML file with no build step. Open it in a browser, or use the live site:
<https://chrisdfennell.github.io/arithmetic-helpers/>
