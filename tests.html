Arithmetic Helpers · for checking the site

Self test

Runs every helper page and checks it gets the right answers. It opens each page in a hidden frame and checks five things: the page loads with all its parts; a list of problems with known answers; Check my answer accepts right answers, catches wrong ones and asks for simplifying; problems from each page’s problem maker, re-worked here by separate code; and that each made problem opens from its link with the same answer. Your saved settings on each page are put back when it finishes.

This page is open as a file, so the browser won’t let it look inside the other pages. Open it from the website, or start a local server in the folder (for example python -m http.server) and open http://localhost:8000/tests.html.
